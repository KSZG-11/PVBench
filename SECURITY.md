# Security policy

Do not commit API keys, access tokens, Hugging Face credentials, cloud credentials, private URLs, local absolute paths, evaluation media, or model weights. Use environment variables or local untracked configuration files for secrets. If a credential has been exposed, revoke and rotate it immediately; removing it from the latest file does not remove it from Git history.

For a suspected vulnerability in this research code, contact the project maintainers through a verified channel before public disclosure. A public contact address will be added when the release owners approve one.
